# Creator Workbench — invite-only alpha boundary

Session: ANEVUM.WEB.BUILD.2026-10-20.001.CREATOR-WORKBENCH-PRIVATE-ALPHA
Source base: V095 canonical React Creator Studio PR #571; design contract PR #570.

A private pilot is controlled by canonical, verified Better Auth member IDs, not guessed handles or hidden links. The founder's existing active staff owner grant controls invitation management, but a Workbench invitation never grants staff access. An owner may select an existing verified handle, issue a time-bounded invitation, renew it, or revoke it. Pilot admission is server-enforced for every request, auditable, capped and default-off.

Alpha work uses the existing private canonical Studio project ID, draft revision and owner-bound save API. No public listing, review approval, provider API keys, executable source upload, XP or RHEN permission can be granted via this Workbench. Browser story preview renders safe declarative text/choices, not user HTML/JS.

Implementation flags remain OFF until staged schema backup/restore, tested member A/member B/staff gate checks, exact-head QA, iPhone Safari acceptance and explicit staging activation. This file alone performs no migration or deployment.
