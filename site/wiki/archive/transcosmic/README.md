# Transcosmic Archive

Status: ARCHIVED  
Archived: 2026-09-25

This folder is the single repository archive for ANEVUM's earlier Transcosmic/publishing-facing website material.

## Why this exists

ANEVUM is now Devon Akins's personal umbrella project and online home. The automated capital system is the current primary build, but it is not the permanent definition of ANEVUM.

The earlier publisher-first identity is therefore preserved here instead of remaining mixed into current Wiki navigation.

## Archived scope

- REPLY, formerly presented as The Transcosmic / Book One
- The Transcosmic public-universe framing
- ANEVUM's former independent-publisher positioning
- Earlier Books, Wiki, Lattice, Store, release-update, and reader-tool concepts
- Public-facing descriptions of the first-contact premise and publishing plan

## Preservation rule

Archived material is historical context, not current operating documentation. It should not be silently deleted or treated as the current ANEVUM model.

If publishing resumes, it can be separated into a new publishing identity while this archive remains intact.
