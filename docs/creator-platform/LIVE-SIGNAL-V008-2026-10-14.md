## Purpose and public interaction

The homepage opens as a rounded, high-definition cosmic **Live Signal** terminal rather than a large marketing pitch. It remains a useful page before the first approved member project exists. The hero is a public directory surface, not an operational status dashboard: no fictional online counts, 98%-health badges, made-up events, fabricated reactions, invented creator images or implied live trades.

Visible sections:
1. **Latest releases:** links for up to three approved published projects, with dates and author identity from the public API.
2. **Conversations:** up to three moderated public discussions, gated by the server-advertised `communityPosts` capability. This is a read-only public surface.
3. **Creator channels:** actual public creator records, linked to channels; displayed count is the genuine `publishedProjects` field, never an approximation or engagement score.
4. **Public signal:** published catalogue counts and a UTC clock. It does not imply real-time platform uptime, member presence, telemetry, sentiment or network reach.

Below the terminal, the existing V006 community feed remains the homepage's primary user content. Project and discussion entries visibly attribute their creators. Filters and links retain existing routes. Do not delete the independent Community Hub V007; it remains the community destination.

## Visual system

- Dark cosmic art using existing source-controlled WebP masters and deterministic SVG fallback. No rasterized text, logos or fake controls.
- Continuance Institute/Transcosmic *document-inspired* typography: book-serif display, neutral sans interface, monospaced small archival metadata. ANEVUM branding remains independent.
- Tactile, distinctly rounded glass modules and buttons with inset edge lighting, bottom compression, clear focus rings.
- Small, subtle animated waveform and blinking terminal caret. Waveform is explicitly decorative, not a sound/uptime visualization. No moving glare sweep, flashing particle storm or looping faux data.
- Real responsive widths: 1440, 1024, 390 and 320. Module grid becomes full-width vertical records on narrow screens. Keep legibility and tap targets.
- Animation paused at reduced-motion settings. Browser refresh every 180 seconds only while tab is visible; last verified public items remain shown through refresh and backend errors, with a truthful stale-data message.

## Data, security and production boundaries

Read-only public data uses the existing API. No D1 migrations, new Workers, R2 buckets, third-party fonts, unreviewed files, authentication sessions, staff privileges, authoring writes or private Lab/RHEN data. Existing member gates and moderation remain server authoritative. No personal founder portfolio in the public feed. The homepage does not create rankings or personalized recommendations.

Categorized automated highlights remain **future** work. They require a distinct backend ingest/curation contract, moderation-safe algorithm, genuine editorial records, provenance, category selection, opt-outs and audit logs. Do not call category excerpts "featured" or "trending" without a genuine scoring/curation authority.
