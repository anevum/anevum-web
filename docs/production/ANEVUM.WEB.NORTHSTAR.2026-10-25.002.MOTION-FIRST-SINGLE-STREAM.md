## 1 — Complete North Star and design rules

### Identity and composition
- **Premium and original:** authored visual composition, clear hierarchy, generous negative space, detailed but controlled illuminated edges, dimensional panels, clean type and genuine high-resolution assets. Avoid generic sci-fi shader fog, a random spinning model or glass cards covering every inch of the screen.
- **One navigation grammar:** consistent Orbital mark, responsive header, meaningful text labels, functional search, accessible mobile menu, one IREN guide, stable Wayfinder/controller focus. A cinematic overlay cannot block keyboard focus, screen readers, gestures or CTAs.
- **Route-specific character:** Arrival cinematic; Discover editorial and efficient; creator/project pages focus on genuine work; Commons exposes real discussions; Studio calm and tool-first; member/RHEN/Command specialist and permission-aware; portfolio and Sites maintain separate product stories but inherit approved parent identity.
- **Responsive by design:** widescreen compositions have real 390px/320px crops, not a shrunken desktop scene. All content and navigation remain useful without video and with forced-colors or reduced-motion.

### Motion taxonomy and budget

| Mode | Use | Implementation rule |
| --- | --- | --- |
| Cinematic ambient | Hero, section backdrop | First-party poster immediately; short responsive MP4/WebM optional after viewport and motion consent/conditions |
| Scroll-directed | One specific story/product transformation | Reviewed bounded image sequence or video scrub with mobile tier; no universal multi-hundred-frame load |
| Section transitions | Expansion, reveal, context shift | CSS or modest WAAPI tied to real semantic state; no focus trap |
| Micro-feedback | Hover, focus, selected state | Fast, reversible, meaningful and reduced-motion friendly |
| Actual interactive 3D | Game/player/simulation/editor viewport | Allowed when the user opens that product; independently performance/security-tested |

Do NOT run multiple large video backgrounds per initial viewport; do NOT start WebGL just to display atmosphere; do NOT hide readable content behind moving layers; do NOT simulate fictitious social activity or invented performance metrics. Motion pauses when offscreen, tab-hidden or user-paused, and does not autostart under reduced-motion or Save-Data.

### One reusable media pipeline

1. **Creative brief:** real page objective, aspect/crop, mobile safe area, copy/Orbital logo negative-space protection, source/license, actual creator identity, art direction and owner signoff.
2. **Master keyframe:** original 2K/4K image if justified; derive responsive AVIF/WebP/poster outputs rather than sending 4K to every device. Static poster must look finished.
3. **Short clip:** edited 6–10 second ambient loop when appropriate, with WebM and MP4/H.264 fallback and no audio autoplay. Store locally/first-party with immutable asset metadata. Exact quality setting depends on device profiling, not a blanket 4K download.
4. **Scroll frames only when needed:** use existing CinematicFramesV136 and cinematic-director support; responsive frame tiers, bounded decoding, limited frame count and meaningful interaction. Draftly's published still → motion → extracted frame model is the technical *reference*, not a requirement to copy its proprietary code or generate 400 frames for every page.
5. **Media contract:** extend existing CinematicMediaContractV136 / manifest approval, origin, hash, dimensions, duration, bytes and poster guards. Record rights, author/source and fallback. No remote media hotlinks, private uploads or unapproved creator screenshot inference.
6. **Native player:** preserve existing CinematicVideoV136, IntersectionObserver / visibility / play-pause, playsInline, muted, no network until needed, lifecycle cleanup and error/static fallback.
7. **QA:** verify 320/390/768/1440/1920, actual phone Safari, 4K/laptop, reduced motion, Save-Data, low bandwidth, Web Vitals and output quality before approving a clip.

Targets to *measure*, not claims currently achieved: p75 mobile LCP <= 2.5s, CLS <= 0.1 and INP <= 200ms; one visible large ambient clip at a time; real user-perceived readability and touch stability before all decoration. Set final encoded size limits from actual media/codec tests.

### Shared thumbnails/cards, not fake media

Use the existing ProjectThumbnail selection: (1) verified reviewed creator-owned cover, (2) separately reviewed project-specific art with rights and attribution, if explicitly supplied, (3) honest deterministic category SVG fallback. Older public Project DTO currently lacks an approved uploaded-cover field; never guess private asset URLs. Preview video on explicit user interaction or approved in-viewport conditions only, pause others, use a static first frame and meaningful accessible alt. Reuse one component/variant set for homepage, Discover, creators, Commons, Boards, project detail, Studio review and public announcements.

**Implemented development state:** the V136 shell no longer mounts the ambient renderer. Arrival uses the existing native MP4/WebM player with posters and accessibility/bandwidth fallbacks. Its current 12-second camera crop of a generated still is an unapproved temporary candidate, not independently animated environmental footage. Sequence/production art approval remains closed.
