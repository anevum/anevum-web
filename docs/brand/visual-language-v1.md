# ANEVUM visual language v1

Status: CANONICAL  
Locked: 2026-10-06

## Hierarchy

- **ANEVUM** — company mark and publisher identity.
- **RHEN** — product/runtime mark.
- **RHEN modules** — Execution, Control, Research, Replay, Forecast, Core, Worker, Command.
- Compatibility names: IREN → Control, GRAEN → Research, VELUM → Replay, NOSTRA → Forecast.

## Slack

Only `:anevum:` and `:rhen:` are active custom ANEVUM-family emoji. Module and status semantics use the canonical native markers defined by the RHEN v3 notification language.

## Module presentation

All RHEN modules use the RHEN blue/cyan visual family. Named modules retain their names, responsibilities, data keys, and routes where required for compatibility, but do not receive independent brand colors or standalone product marks.

## State presentation

Identity and state are separate. Active/healthy/warning/critical/waiting/risk/evidence semantics may change color according to runtime state; the underlying module identity does not.

## Website icons

Use `RhenModuleGlyph` / `SystemIcon` for module identity. Use `UiIcon` for navigation, nouns, and actions.

Do not introduce new standalone subsystem SVG marks, per-module color families, or one-off Unicode UI icons without updating this canonical registry first.
